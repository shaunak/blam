# Blam implementation plan

Goal: Deliver one playable multiplayer arena with a laptop server.
Architecture: Share simulation code between Node and browsers. Keep signaling separate from simulation.
Stack: TypeScript, Babylon.js, werift, ws, Vite, Node tests, Playwright.
Spec: docs/superpowers/specs/2026-09-26-blam-design.md

## Tasks

- [x] Implement simulation in src/game.ts with tests/game.test.ts. Exercise collision, shields, deaths, respawns, duplicate and late shots.
- [x] Implement src/signaling.ts and src/host.ts. Exercise two real WebRTC peers and channel delivery settings.
- [x] Implement src/client.ts, src/style.css, and index.html. Exercise browser rendering, movement, combat, and host shutdown.
- [x] Write setup instructions and TURN configuration. Run the build, all tests, and a real browser smoke test.

## Review focus

Reject non-finite input, future timestamps, stale life numbers, and duplicate shot IDs.
Stop motion after input loss and prevent unlimited queues under stalled connections.
Keep room capacity correct after failed negotiation or browser closure.
Keep cover geometry and player geometry equal across rendering and hit tests.
Distinguish proven local play from unproven public-network and TURN deployment.

## Execution decisions

The user supplied the scope and requested immediate implementation. Execute inline in this empty workspace.
Use current-position hit tests with a 500 ms age limit. Add historical rewind only after latency playtests justify it.

## Results

Six simulation tests pass. The TypeScript build passes.
Two Chrome clients pass the gameplay test with direct connections, forced TURN over UDP, and forced TURN over TCP.
The browser test also rejects a third player and tests host-browser departure and server shutdown.
An independent source review found no additional important defects.
Screenshots were inspected. Public services and a separate-network playtest remain external acceptance work.

The first browser run exposed a missing Babylon edges-renderer import. The browser test passed after the import was added.
Negotiation now gets 25 seconds before timeout. Active players get a separate 10-second silence timeout.
Werift retains a TURN refresh timer after close. The standalone host and browser test exit after transport cleanup.
Vite reports a large Babylon bundle. This MVP keeps one bundle instead of extra loading code.
