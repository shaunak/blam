# Main menu and readable invites

Goal: Start Game creates a two-player room. A three-word invite joins that room.

Architecture: The existing laptop process owns room simulations and signaling. One private Vercel Blob records the active laptop address and a gateway key. A Vercel function forwards room creation and lookup to that laptop. Gameplay remains WebRTC. Existing full invite URLs remain usable.
